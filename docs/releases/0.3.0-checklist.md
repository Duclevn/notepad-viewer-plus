# Notepad Viewer Plus 0.3.0 release checklist

**Candidate date:** 2026-09-29  
**State:** Local technical candidate; not approved or published

## Release-page summary

Notepad Viewer Plus 0.3.0 adds a high-contrast, dark-mode-aware Notepad++ toolbar button for the existing preview toggle, replaces the obsolete Open Settings command with a native About dialog containing a bulleted format summary, and introduces reproducible x64/x86 Plugin Admin packaging. The plugin remains an offline-by-default, docked viewer for Markdown, Mermaid, PlantUML, HTML, SVG, JSON, YAML, XML, CSV/TSV, OpenAPI, images, and PDF.

The Microsoft Edge WebView2 Evergreen Runtime is required. ARM64 is not supported.
